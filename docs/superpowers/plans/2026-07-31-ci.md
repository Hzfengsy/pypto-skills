# Continuous Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a read-only GitHub Actions CI workflow that runs all repository
tests on Python 3.10 and 3.14, requires operational Bubblewrap isolation, and
enforces pinned Python and shell quality checks.

**Architecture:** Keep CI-only policy helpers and their unit tests under
`tests/`, repository tool configuration at the root, and orchestration in one
`.github/workflows/ci.yml` workflow. Split static quality checks from the
Python compatibility matrix so failures are attributable and both matrix
results remain visible.

**Tech Stack:** GitHub Actions, Ubuntu 22.04, Python 3.10/3.14,
standard-library `unittest`, Bubblewrap, Ruff 0.16.0, Pyright 1.1.410, Bash.

## Global Constraints

- Run on pull requests, pushes to `main`, and manual dispatch.
- Use `ubuntu-22.04`; do not disable host user-namespace security controls.
- Give the workflow only `contents: read` permission.
- Use `persist-credentials: false` for every checkout.
- Pin `actions/checkout` 6.0.2 and `actions/setup-python` 6.2.0 to full commit
  IDs.
- Target Python 3.10 in static configuration and test Python 3.10 plus 3.14.
- Set `PYPTO_SKILLS_REQUIRE_BWRAP=1` in CI and fail when the production
  validation sandbox cannot execute its capability probe.
- Keep local test behavior unchanged when the CI flag is absent.
- Discover tests and tracked shell files dynamically; do not hard-code the
  current test count or shell-script list.
- Never add runtime dependencies to the portable skills bundle.
- Do not use `continue-on-error`, and set the matrix `fail-fast` value to
  `false`.

```python
from __future__ import annotations

import os
import unittest

REQUIRE_BWRAP_ENV = "PYPTO_SKILLS_REQUIRE_BWRAP"


def enforce_validation_sandbox(operational: bool) -> None:
    if operational:
        return

    message = "bubblewrap isolation is unavailable and fails closed"
    if os.environ.get(REQUIRE_BWRAP_ENV) == "1":
        raise AssertionError(f"{message}; {REQUIRE_BWRAP_ENV}=1")
    raise unittest.SkipTest(message)
```

- [ ] **Step 3: Create the workflow**

Create `.github/workflows/ci.yml`:

```yaml
name: CI

on:
  pull_request:
  push:
    branches: [main]
  workflow_dispatch:

permissions:
  contents: read

concurrency:
  group: ci-${{ github.workflow }}-${{ github.event.pull_request.number || github.ref }}
  cancel-in-progress: true

jobs:
  quality:
    name: Quality
    runs-on: ubuntu-22.04
    timeout-minutes: 10
    steps:
      - name: Check out repository
        uses: actions/checkout@de0fac2e4500dabe0009e67214ff5f5447ce83dd # v6.0.2
        with:
          persist-credentials: false

      - name: Set up Python
        uses: actions/setup-python@a309ff8b426b58ec0e2a45f0f869d46889d02405 # v6.2.0
        with:
          python-version: "3.14"

      - name: Install quality tools
        run: python -m pip install --requirement requirements-ci.txt

      - name: Lint Python
        run: ruff check tests

      - name: Check Python formatting
        run: ruff format --check tests

      - name: Type-check Python
        run: pyright

      - name: Check shell syntax
        run: git ls-files -z -- '*.sh' | xargs -0 -r -n 1 bash -n

  tests:
    name: Tests (Python ${{ matrix.python-version }})
    runs-on: ubuntu-22.04
    timeout-minutes: 20
    strategy:
      fail-fast: false
      matrix:
        python-version: ["3.10", "3.14"]
    steps:
      - name: Check out repository
        uses: actions/checkout@de0fac2e4500dabe0009e67214ff5f5447ce83dd # v6.0.2
        with:
          persist-credentials: false

      - name: Set up Python
        uses: actions/setup-python@a309ff8b426b58ec0e2a45f0f869d46889d02405 # v6.2.0
        with:
          python-version: ${{ matrix.python-version }}

      - name: Install Bubblewrap
        run: |
          sudo apt-get update
          sudo apt-get install --no-install-recommends --yes bubblewrap

      - name: Run tests with required isolation
        env:
          PYPTO_SKILLS_REQUIRE_BWRAP: "1"
        run: python -m unittest discover -s tests -v
```
